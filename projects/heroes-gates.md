# Heroes Gates / Врата Героев

**Focus:** technical game design and browser delivery.

[Play the web build](https://snodrod.github.io/heroes-gates-play/) · [Build repository](https://github.com/Snodrod/heroes-gates-play)

A turn-based tactics project inspired by Heroes III, built with Godot 4.5.1. The public repository contains the exported web build; development source remains private.

The repository describes a production pipeline using 3D models, Adobe Mixamo animation, Blender rendering and procedural sound synthesis.

**Evidence:** public build repository and its documented play URL. The game was not play-tested during this portfolio review.

**Boundary:** the public repository is a playable showcase, not an open-source code sample. Third-party animation tooling is credited rather than presented as wholly original work.
