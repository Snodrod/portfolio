# Scenario Platform

**Focus:** an AI-assisted creative product with collaboration and permissions.

[Source](https://github.com/Snodrod/scenario-platform)

A platform that turns scripts into scenes and storyboard frames, generates frame images, collects client comments and exports the result as a PDF.

Project documentation describes a script editor, AI scene/frame breakdown, character references, real-time comments, project roles, team management and Notion import. Storyboard frames carry dialogue, delivery, editing and audio instructions, rather than images alone.

**Stack:** Next.js 16, TypeScript, Supabase/Postgres/Auth/Storage, model-provider integrations and Vercel.

**Evidence:** public repository plus local README and handoff documentation. These describe implemented features; the hosted deployment was not acceptance-tested for this portfolio.

**Boundary:** development MVP. Google OAuth/Drive and provider billing need environment configuration; an implemented integration is not necessarily enabled in the hosted environment.
