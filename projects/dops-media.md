# Dops Media

**Focus:** creative production, product presentation and a lightweight website.

[Studio website](https://dops.media)

A bilingual EN/RU website presenting a studio's production, postproduction and AI-content services. The site uses static HTML/CSS/JavaScript with Vercel serverless functions, a filtered work gallery, service tabs and a project-enquiry flow.

The documented creative direction uses an editing-room visual language: dark backgrounds, a signal-orange accent, timecodes and a CGI orbital scene. The project demonstrates how technical implementation supports a creative brief and a client-facing workflow.

**My documented studio role:** postproduction, CGI and AI. Live-action client films credited to other team members are not presented as my individual work. AI/CGI capability demos are distinguished from commissioned client projects.

**Evidence:** curated Obsidian project note and local project documentation. The production website was not revalidated during this portfolio review.
