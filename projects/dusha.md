# Dusha / Душа

**Focus:** progression, encounter pacing and mobile game systems.

A Godot 4.5 survivor prototype for Android and Windows. The player moves a creature with a joystick while it attacks automatically. Kills generate experience, each level-up offers one of three upgrade cards, and completing an encounter unlocks persistent evolution.

Wave completion depends on clearing a spawn budget, connecting build strength to pacing. A ten-wave level ends with a boss. Difficulty adjusts health, damage, spawn frequency and experience together. The project also includes a character editor, touch controls and portrait/landscape layouts.

**Evidence:** local README describes version 0.4.0, Android APK/AAB builds, a 208-test harness, balance simulation and frame benchmarks. These are documented results, not freshly rerun checks.

**Boundary:** local prototype; no public download or commercial release is claimed. Source and bundled assets are not included in this portfolio.
