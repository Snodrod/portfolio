## How I work

- Define the product loop, constraints and acceptance criteria before implementation.
- Split systems into modules with clear ownership and integration interfaces.
- Use AI coding agents for implementation, guided by specifications and review.
- Keep state changes observable and use human approval where the workflow requires it.
- Separate implemented behavior from product goals and future work.

Technologies used across these projects include Godot/GDScript, TypeScript, Next.js, Supabase, PostgreSQL, Redis, Docker, Anthropic-compatible APIs, MCP tooling and Vercel. Project usage does not imply equal depth in every technology.
